# 隱私權政策 — X 發文前成人內容預檢

最後更新：2026 年 10 月 21 日（適用版本 0.5.4）
網址：[PRIVACY_POLICY_URL]

## 概要
本擴充功能幫你在 X（x.com）發文前，預估圖片或影片可能被判為敏感內容的風險。**我們沒有自己的伺服器，不收集、不上傳、不出售任何資料，也沒有任何分析或追蹤程式。**

## 在你電腦本機處理的資料
- **圖片與影片畫面**：你在 X 發文框加入的媒體，以及（如你開啟「掃描時間軸圖片」）畫面上看到的貼文圖片，會在你的瀏覽器內用打包在擴充功能裡的開源模型 NSFWJS 分析。分析結果不會離開你的電腦。
- 時間軸圖片由擴充功能直接從 X 的圖片伺服器（pbs.twimg.com）下載到你的瀏覽器分析，下載時不帶你的登入 cookie。

## 存在你電腦裡的資料（chrome.storage.local）
- 媒體發文紀錄：每則只存時間、是否疑似、是否高風險、媒體數量；保留最多 30 天、200 筆。不存圖片、文字或帳號資訊。你可在工具列彈窗按「清除 24h 發文計數」清除。
- 設定：是否掃描時間軸、你選的 OpenAI 模型名稱。
- 你自己的 OpenAI API 金鑰（若有填）：只存在本機，不會傳給我們，只用於向 OpenAI 發出你按下的「問 AI」請求。
- 分數與 AI 回答的暫存只在分頁記憶體中，關閉分頁即消失。

## 傳送給第三方的資料：只有在你按「問 AI」時
- 按下「問 AI」後，該媒體的縮圖（最長邊 768px 的 JPEG；影片取一格畫面）和固定的提示文字，會用**你自己的 API 金鑰**直接送到 OpenAI（api.openai.com）。不會送出你的 X 帳號、貼文文字或其他資訊。
- OpenAI 如何處理這些資料依 OpenAI 的政策與你帳號的設定。**若你的 OpenAI 組織開啟了資料分享（例如換取免費額度），這些圖片和回答可能被 OpenAI 用於訓練模型。** 參考：https://openai.com/policies/
- 不按「問 AI」就不會有任何資料傳給 OpenAI。

## 不做的事
- 不出售、不出租、不分享資料給任何人。
- 不使用分析、廣告或追蹤工具。
- 不讀取你的 X 私訊、密碼或登入資訊。
- 不從網路下載或執行遠端程式碼。

## 刪除資料
移除擴充功能即刪除所有本機資料；也可在彈窗清除計數，或清空金鑰欄位後重新儲存。

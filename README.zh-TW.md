# 發文前敏感媒體預檢（Sensitive-Media Pre-check for X）

[English](README.md)

Chrome／Brave（MV3）擴充功能：**在 X 發文前，於本機預估圖片／影片被標為敏感媒體的風險**，並提醒 24 小時內的疑似媒體發文次數。

> **與 X 無關。** 使用開源 NSFWJS 模型，**不是 X 的判斷模型**，結果僅供參考。

## 功能
- **發文預檢**：在發文框加入／貼上／拖放媒體，面板顯示「正常／疑似／高風險」與百分比。影片和 GIF 抽 5 格取最高分。
- **24 小時計數**：按「發佈」時記錄；24 小時內已有 2 則疑似媒體（第 3 則可能讓帳號被標記約 7 天），或最近 5 則有 2 則高風險時警告。
- **時間軸標籤**（選用，預設關閉）：畫面上貼文圖片角落顯示風險標籤（影片用封面圖）。
- **問 AI**（選用）：用你自己的 OpenAI 金鑰送出縮圖，顯示精簡卡片：風險 低／中／高、一句結論、因素表、最多 3 條修改建議。AI 判「中／高」會升級本機標籤（只升不降）。
- **滑鼠停留顯示大圖（所有網站）**（預設開啟，可設定不要放大的網站）：滑鼠停在圖片約 0.3 秒就在旁邊顯示原圖（含頭像、卡片圖、影片封面），已掃描過的會在角落顯示風險標籤。按住 Shift 暫停；Esc、捲動、點擊關閉。預覽時**按右鍵釘選**到畫面中央：滾輪縮放、拖曳移動，再按右鍵、Esc 或點背景關閉。
- 整個瀏覽器共用一份模型（offscreen 文件），重新整理分頁不用重載。

> **權限提醒：** 因為大圖預覽在所有網站上運作，安裝時 Chrome 會顯示「讀取及變更你在所有網站上的資料」。放大功能只讀取網頁上的圖片網址來顯示預覽，不會傳送任何資料；不需要可在彈窗關閉。

## 安裝
1. 下載或 clone 本 repo。
2. 打開 `chrome://extensions`（Brave 為 `brave://extensions`），開啟「開發人員模式」。
3. 「載入未封裝項目」→ 選 `extension/` 資料夾。需 Chrome／Brave 116 以上。

## 分數怎麼算
- 模型：NSFWJS 4.3.0 **InceptionV3**（299×299），TensorFlow.js 4.22.0（WebGL，失敗改用 CPU）。
- 風險 = Porn + Hentai + 0.6 × Sexy（上限 100%）。
- 門檻（本專案自訂，不是 X 的）：圖片 ≥ 50% 疑似、影片 ≥ 35% 疑似、≥ 80% 高風險。

## 隱私
- 分類全在本機；沒有我們的伺服器、沒有分析追蹤。
- `chrome.storage.local` 存：設定、（選填）OpenAI 金鑰、發文紀錄（時間＋是否疑似／高風險，最多 30 天、200 筆）。
- 只有按「問 AI」時，最長邊 768px 的縮圖會用你的金鑰送到 api.openai.com；若你的 OpenAI 組織開啟資料分享，可能被用於訓練。
- 完整政策：[docs/privacy-policy.zh-TW.md](docs/privacy-policy.zh-TW.md)

## 限制
- 不是 X 的模型，判斷可能不同。
- **盲點**：NSFWJS 對透視／緊身衣物、身體曲線強調、沒有裸露的暗示性構圖或姿勢判斷較弱，而這些正是常被標記的情況，建議搭配「問 AI」。
- 計數只看得到這個瀏覽器設定檔、經本擴充功能發出的貼文；發文失敗也會被算。
- 依賴 X 頁面結構（data-testid），X 改版可能失效。
